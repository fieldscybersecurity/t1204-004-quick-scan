Getting Started Guide
ClickFix℠ Quick Scan Script v1.0.0

Welcome to the ClickFix℠ Quick Scan

This guide walks you through downloading, verifying, and running the ClickFix℠ Quick Scan Script on a single workstation or across your entire fleet. No installation, no admin rights, no internet connection required. The script is read-only and makes zero changes to your system.

1 Download the Script

Download quickscanscript.ps1 from the official source:

  • Visit clickfix.com/quick-scan and click Download Quick Scan Script.
  • Save the file to a location you can find easily, such as your Downloads folder or Desktop.
Tip: The script is a single .ps1 file with no external dependencies. There is nothing to install or unzip.

2 Verify the File (Recommended)

Before running any script you download from the internet, verify its integrity by comparing its SHA-256 hash to the value published on the download page.

# Open PowerShell and run:
(Get-FileHash '.\quickscanscript.ps1' -Algorithm SHA256).Hash

The expected hash is:

SHA-256: DEC22A755C9B92DFC53E5B6B8E883DD73E3A23CC2EF76BE2FCAF7F252B1C06F7

If your output does not match, do not run the file—download a fresh copy from clickfix.com/quick-scan.

Important: If the hashes do not match, the file may have been tampered with in transit. Delete it and download again from the official site.

3 Open PowerShell

You do not need to “Run as Administrator.” The script works in a standard (non-elevated) PowerShell window. Some checks will note when admin privileges would provide additional detail, but all 12 checks run without them.

  • Press Win + S, type PowerShell, and click Windows PowerShell.
  • Or right-click the Start button and select Windows PowerShell.

4 Navigate to the Script

Change to the folder where you saved the file. If you saved it to your Downloads folder:

cd "$env:USERPROFILE\Downloads"
Tip: You can also drag and drop the folder from File Explorer into the PowerShell window after typing cd  (with a space).

5 Run the Script

Execute the script with:

& '.\quickscanscript.ps1'

The scan completes in under 30 seconds. Results appear in your console with color-coded pass/fail indicators.

Execution Policy Error?

If PowerShell blocks the script with an execution policy error, use this one-time bypass (it does not change your system’s policy):

powershell -ExecutionPolicy Bypass -File '.\quickscanscript.ps1'

6 Read Your Results

Each of the 12 checks reports one of three outcomes:

ResultMeaning
✅ PASSThe defensive control is active and properly configured.
❌ FAILThe control is missing or misconfigured. A remediation suggestion is provided.
⚠️ MANUAL CHECKThe control requires human review to confirm its configuration.

7 Export Your Results (Optional)

You can save results for documentation, audits, or to upload to the ClickFix℠ Score & Readiness Assessment.

Export as HTML Report

& '.\quickscanscript.ps1' -ExportHTML

Opens a branded, color-coded report in your default browser.

Export as JSON

& '.\quickscanscript.ps1' -ExportJSON

Saves a machine-readable file you can upload to the ClickFix℠ Score & Readiness Assessment for a full remediation roadmap.

Save to a Specific Folder

& '.\quickscanscript.ps1' -ExportHTML -OutputPath "C:\Reports"

Combine Both Exports

& '.\quickscanscript.ps1' -ExportJSON -ExportHTML
Enterprise Deployment

The ClickFix℠ Quick Scan Script is designed for enterprise-scale deployment. Because it is a single, self-contained .ps1 file with no dependencies, it works with every major endpoint management platform.

Microsoft Intune

Deploy the script as a PowerShell script package through the Intune admin center:

# Intune portal → Devices → Scripts → Add (Windows 10 and later)
# Upload: quickscanscript.ps1
# Settings:
# Run this script using the logged-on credentials: Yes
# Run script in 64-bit PowerShell host: Yes
# Enforce script signature check: No

# To collect HTML reports centrally, use -ExportHTML -OutputPath:
& '.\quickscanscript.ps1' -ExportHTML -OutputPath "\\server\ClickFix(SM)-Reports$\%COMPUTERNAME%"

Microsoft SCCM / MECM

Create a Package (not an Application) with a Program that runs the script:

# Package source: \\sccm-source\packages\ClickFix\
# (place quickscanscript.ps1 in this share)

# Program command line:
powershell.exe -ExecutionPolicy Bypass -File ".\quickscanscript.ps1" -ExportJSON -ExportHTML -OutputPath "\\server\ClickFix(SM)-Reports$\%COMPUTERNAME%"

# Run mode: Run with user's rights
# Deploy to: Device collection (target OUs or All Workstations)

Group Policy (GPO)

Use a Startup Script or Logon Script GPO to run the script across a domain:

# 1. Copy script to SYSVOL (accessible by all domain machines):
# \\domain.local\SYSVOL\domain.local\scripts\quickscanscript.ps1

# 2. Create or edit a GPO:
# Computer Configuration → Policies → Windows Settings
# → Scripts (Startup/Shutdown) → Startup → PowerShell Scripts

# 3. Script name:
"\\domain.local\SYSVOL\domain.local\scripts\quickscanscript.ps1"

# 4. Parameters (optional):
-ExportJSON -ExportHTML -OutputPath "\\server\ClickFix(SM)-Reports$\%COMPUTERNAME%"

Collecting Reports Centrally

Regardless of deployment method, point -OutputPath to a UNC share to collect all results in one place. Create a share with a subfolder per machine using the %COMPUTERNAME% variable:

# Example share structure after scanning 3 machines:
\\server\ClickFix(SM)-Reports$\
  ├── desktop-abc\
  │   ├── ClickFix(SM)-quick-scan-desktop-abc-20261009-143022.html
  │   └── ClickFix(SM)-quick-scan-desktop-abc-20261009-143022.json
  ├── laptop-xyz\
  │   ├── ...
  └── server-01\
      ├── ...
Tip: Upload the JSON files to the ClickFix℠ Score & Readiness Assessment for a prioritized, org-wide remediation roadmap.
